# Data Structures & Algorithms (DSA) Projects

A collection of coursework and programming exercises focused on data structures, algorithms, and problem-solving.

## About this repository

I use this repository to organize my DSA work and document what I learn while studying software engineering at Morehouse College. Projects and exercises may cover topics such as:

- Arrays, linked lists, stacks, and queues
- Recursion and searching
- Trees and other data structures
- Algorithm analysis and time complexity
- C++ programming, debugging, and testing

Individual assignments may use different source files, build instructions, or branches. See the relevant project files for implementation details.

## Technologies and skills

- **Primary language:** C++
- **Concepts:** Data structures, algorithms, object-oriented programming, and problem-solving
- **Tools used in my coursework:** Git, CMake, Catch2, and CTest (not necessarily used in every project)
